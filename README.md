# Dump Search Tool

The Dump Search Tool is a bash script designed to search for a specific term within files in a selected folder and its subfolders. It provides a graphical interface using Zenity for file and folder selection and allows the user to save the search results to a specified file.

## Prerequisites

Before using the Dump Search Tool, ensure that you have 'aha' installed. If not, the script will attempt to install it using pip.

```bash
pip install aha
```

## Usage

1. Clone the repository or download the script.
2. Make sure the script has execute permissions:

```bash
chmod +x ddst.sh
```

3. Run the script:

```bash
./ddst.sh
```

4. You will be greeted with a welcome message and prompted to select a file or folder to search.
5. Enter the search term and select the output file where the results will be saved.
6. Click "Save" or "Open" to proceed with the search.
7. The search results will be displayed, and the output will be saved to the specified file in HTML format.
8. You can review the results in the output file.

## How It Works

The script uses Zenity for graphical file and folder selection. It then searches for the specified term within the selected files and folders using grep. The search results are formatted with color highlighting using GREP_COLORS and displayed using aha. Finally, the results are saved to an HTML file.
